# 🕷️ The Polite Scraper

A polite web scraper that respects robots.txt and includes delays between requests.

## 🚀 Features

- Polite scraping with delays
- Respects robots.txt
- Saves data to CSV and JSON
- Error handling
- User-Agent rotation
- Clean code structure

## 🛠️ Technologies

- Python 3.10+
- Requests
- BeautifulSoup4
- lxml

## 🔧 Installation

```bash
git clone https://github.com/muzzammilahmed18/polite-scraper.git
cd polite-scraper
python -m venv venv
venv\Scripts\activate

📊 Usage
bash
